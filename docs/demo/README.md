# Demo GIFs

Terminal recordings of this API. No browser UI is involved.

The README top links three files: fresh boot plus `/health`, kill -9 resume, and
a second terminal prompt. `second-terminal.gif` is a second local terminal, not
a phone or Termux recording. No phone was available. The HTTP call is the one a
phone would make.

Recorded from a real pty with `pyte`, rendered to PNG frames, encoded with
ffmpeg. The commands and output are real.
